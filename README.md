# Rostinho · Central de posts

Página com os criativos do Rostinho prontos para o Instagram: imagem para salvar, legenda, hashtags e texto alternativo.

- `index.html` — o sistema (abre direto no GitHub Pages)
- `img/full` — imagens originais 1080 px para publicar
- `img/web` — prévias leves
- `zip` — carrosséis em .zip
- `src/posts.json` — legendas e hashtags (edite aqui e rode `python3 src/build_html.py` depois de `src/build_assets.py`)
